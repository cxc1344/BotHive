# BotHive 0.7.0 验证清单

0.7.0 是在**没有 Kotlin 编译器**的环境里写完的：每个文件都做过括号与字符串配平检查、全局符号与调用点核对、接口签名比对，但**没有真正编译过，也没有在真机上跑过**。发布前请按顺序完成下面三步。

## 1. 编译与单元测试（必做）

```bash
bash tools/fetch_proot_android.sh
gradle testDebugUnitTest assembleRelease --no-daemon
```

一共 11 个测试文件、85 个用例。下面这些写法最可能出编译问题，请优先看：

| 文件 | 写法 | 不行时怎么改 |
|---|---|---|
| `BixCompanion.kt` | `CanvasDrawScope.draw(...)` 带具名参数；`androidx.compose.ui.graphics.Canvas(android.graphics.Canvas)` | 改成位置参数；改用 `androidx.compose.ui.graphics.Canvas(imageBitmap)` |
| `UiMotion.kt` / `BixCompanion.kt` | `DrawScope.inset` 传负的 right / bottom | 改成先 `translate` 再 `clipRect` |
| `GlassStyle.kt` | `ContextCompat.registerReceiver(..., RECEIVER_EXPORTED)` | 系统广播改用 `RECEIVER_NOT_EXPORTED`，或者直接用 `context.registerReceiver` 并加 API 判断 |
| `Ui.kt` | `androidx.activity.compose.PredictiveBackHandler`、`BackEventCompat.EDGE_LEFT` | activity-compose 1.9.2 里有；如果报错，退回 `BackHandler` |
| `Ui.kt` / `UiExtra.kt` / `UiHive.kt` | `androidx.compose.ui.platform.LocalLifecycleOwner` | Compose 1.7 里已标记过时但仍可用；报错就改成 `androidx.lifecycle.compose.LocalLifecycleOwner` 并加依赖 `androidx.lifecycle:lifecycle-runtime-compose` |
| `UiHive.kt` | `ClipDescription.EXTRA_IS_SENSITIVE`（API 33） | 已加 `SDK_INT >= 33` 判断；compileSdk 35 可以编译 |
| `UiHive.kt` | `KeyboardType.Decimal` | Compose 1.7 里有；没有就换 `KeyboardType.Number` |

## 2. 真机重点测试

按风险从高到低排列：

1. **旧存档升级**：拿一份 0.6.5 的数据（最好置顶过对话、有例行任务和 Provider），覆盖安装后重启：
   - 聊天记录、Bot、Key 都还在
   - 设置页没有出现「存档有 N 处无法读取」
2. **审批与哨兵**：
   - 把「删除」设为「先问我」，让 Agent 删一个测试文件：审批卡出现在「需要你」和对话里，哨兵结论几秒后更新
   - 「执行」和「拒绝」都能正常接着跑
   - 让 Bot A 用 `ask_bot` 叫开启了「命令先批准」的 Bot B 跑 shell：审批卡出现在 A ⇄ B 的私聊里
3. **支付交还**：打开支付宝或银行 App，让 Agent 在主屏上点击：应返回「交给你」，屏幕不会被点击。
4. **保险箱**：存一个测试密码，让 Bot 在 AI 浏览器的登录页调用 `browser_fill_secret`：
   - 输入框被填上
   - 对话、工具输出、审计回放里都看不到明文
5. **通知触发**：建一个「收到微信通知且包含『测试』」的例行任务，让别人发一条消息：
   - 任务在间隔内只触发一次
   - 运行记录里有这次运行
   - 验证码已打码
6. **Webhook**：开启后在手机上用 Termux 测试：
   - `curl -X POST -H "Authorization: Bearer <令牌>" -d "hello" http://127.0.0.1:17321/hook/<id>` 返回 202
   - 令牌错误时返回 401
7. **流光与截屏**：主屏模式下让 Agent 连续 `screen_shot` + `tap_at`：
   - 屏幕边缘有流光和 Bix
   - 截图里没有流光
   - 停止操作后约 2.5 秒淡出
8. **虚拟屏**：切换缩放档位、折叠和展开，跑一个 `phone_task`：
   - 步数进度环正常
   - 不闪退、不卡顿
9. **示教**：
   - 升级后先在系统无障碍设置里把 BotHive 关掉再打开（新版需要更多事件类型）
   - 录一段操作后点「生成技能草稿」，能跳转到技能编辑页
10. **玻璃与动效**：
    - 拖动强度滑杆
    - 打开省电模式：强度被限制、动画停止，卡片上有 Bix 提示
    - Android 14+ 上试预测性返回手势
11. **后台保活**：开启后划掉 App，几秒后常驻通知重新出现（文案是 Bix 口吻）。
